## 根因

**审批的设计是单通道的**：只投递给发起请求的那个页面。因此当
（a）同一会话在多个前端各开一份、用户在看非发起的那份，或
（b）发起页面被刷新/关闭/渲染层卡死，或
（c）承载它的前端进程已死
—— 提示就孤儿化，永远无法被点击，而 agent 会无限等待。

`approval: "ask"` 意味着 agent 每次要碰沙箱外的文件都会产生一次这样的阻塞点，所以复发概率很高。
