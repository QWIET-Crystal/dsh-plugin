## 根因

命令缺 `--test-timeout`。worker 卡死后 `node --test` 无限等待，作业永不结算，agent 的 `job_output` 轮询也就永远返回 `running`。
**副因（误导性极强）**：`2>&1 | Select-Object -Last 25` 会缓冲全部输出，跑到一半看不到任何进展，使"没有输出"既可能是死锁、也可能只是被缓冲——这条管道让排查难度翻倍。

## 处置与结果

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1 | 掐掉两个"孤独端口 + 零 CPU"的 worker | runner 立刻复活，CPU 5.00→5.61，WS 6.4→20.6MB |
| 2 | 观察换代，发现新 worker 又抱端口（打地鼠） | 确认不是一次性故障，而是系统性缺陷 |
| 3 | 部署常驻守护自动收割 | 后续 3 次死锁均被自动处理 |
| 4 | agent 最终拿到完整测试结果 | 756 tests / 687 pass / 54 fail |
