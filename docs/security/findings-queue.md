## 为什么有"越界"记录

第 4 轮发现 1 条严重（空帧风暴，宿主冻结 11 秒 / RSS 1.3GB / deep 下 OOM）时，
桌面端会话已空闲 1.5 小时（最后提交 12:53，当时 14:31）。按约定 `lib/sessions.js` 属于桌面端，
但让一条"一条 HTTP 请求就能打崩宿主"的洞挂着等对方上线，不符合"严重/高危当场修"的用户要求。
所以**由主控直接落地并在提交信息里写明**。此文件用于事后对账，不是流程豁免。
